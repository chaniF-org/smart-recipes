# מטעמים · אב-טיפוס עיצובי (גרסה 1.0)

אב-טיפוס HTML לחיץ של אתר המתכונים החכם, לפי האפיון גרסה 2.

## איך פותחים
1. מחלצים את קובץ ה-ZIP לתיקייה.
2. פותחים את **presentation.html** בדפדפן (Chrome / Edge / Safari). זו מפת המסכים להצגה ללקוח.
3. או נכנסים ישר לאתר דרך **index.html**.

לא נדרשת התקנה ולא שרת. הגופנים נטענים מ-Google Fonts, ולכן מומלץ חיבור לאינטרנט בזמן ההצגה (בלי חיבור יוצגו גופני מערכת).

## זרימה מומלצת להצגה
בית ← גלגל האתגר (סובבו, ⟳ למצרך, צור מתכון) ← מיזוג מטבחים (גררו כרטיס אל כרטיס) ← מתכון לפי בקשה (למשל עוגת יום הולדת) ← מה יש לי (כתבו מצרכים, זהו, צרו מתכון) ← מתכנן תפריט ← תפריט ← עמוד מתכון (מנות, "אין לי", המרת כשרות) ← מצב בישול (טיימרים, הקראה) ← רשימת קניות.

כדאי גם לכתוב לעוזר בצד, למשל: "ארוחת ליל שבת ל-12", "אין לי סילאן", "בוא נתחיל לבשל", "יש לי עוף, תפוחי אדמה ובצל".

## מה בתיקייה
| קובץ | תוכן |
|---|---|
| presentation.html | מפת מסכים עם תצוגות מקדימות למחשב ולמובייל |
| index.html … admin.html | 15 המסכים (כולל request.html ו-pantry.html) |
| states.html | מצבי טעינה, שגיאה, מכסה וריקנות |
| docs/design-document.html | מסמך העיצוב הכללי, כולל רכיבים חיים |
| docs/design-tokens.json | טוקנים למפתחים |
| assets/css/styles.css | מערכת העיצוב המלאה |
| assets/js/ | מעטפת משותפת ונתוני דוגמה |
| assets/img/ | 14 איורי מנות (SVG) |

## הערות
- כל הנתונים הם דוגמאות. היצירה "בזרימה" מדומה בצד הלקוח, ללא קריאות AI.
- גרסת האנגלית (LTR) מתועדת במסמך העיצוב ותיבנה בשלב הפיתוח.
- הקראה קולית במצב בישול עובדת בדפדפנים שיש בהם קול עברי (למשל Chrome / Edge).
